# Я Больше!

Портал терапевта и клиента: загрузка записи сессии, быстрая локальная расшифровка через faster-whisper Small с резервным NVIDIA Parakeet TDT 0.6B v3, подготовка черновика анализа и публикация подтверждённых материалов клиенту. Исходные медиафайлы и дословные расшифровки по умолчанию не хранятся.

## Что запускается

- веб-приложение React + Node.js;
- MySQL для аккаунтов и материалов;
- Caddy для домена и автоматического HTTPS;
- Whisper работает через OpenAI API, поэтому GPU на сервере не нужен.

## Быстрый запуск на сервере

Полная простая инструкция находится в [DEPLOY.md](DEPLOY.md).

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
```

Секреты и загруженные записи не хранятся в GitHub. Записи обрабатываются в оперативной памяти и не входят в резервные копии; резервируется только база с рабочими материалами.
