# Я Больше!

Портал терапевта и клиента: загрузка записи сессии, локальная расшифровка через faster-whisper Medium, подготовка черновика анализа и публикация подтверждённых материалов клиенту.

## Что запускается

- веб-приложение React + Node.js;
- MySQL для аккаунтов и материалов;
- Caddy для домена и автоматического HTTPS;
- Whisper работает через OpenAI API, поэтому GPU на сервере не нужен.

## Быстрый запуск на сервере

Полная простая инструкция находится в [DEPLOY.md](DEPLOY.md).

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
```

Секреты и загруженные аудиозаписи не хранятся в GitHub. Для реальной работы обязательно настройте резервное копирование базы и каталога загрузок.
